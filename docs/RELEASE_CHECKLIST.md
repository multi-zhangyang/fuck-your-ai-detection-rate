# 发布检查清单

## 自动检查

```powershell
python scripts/run_regressions.py --include-browser-e2e --fail-fast
```

该命令覆盖核心 Python 回归、编译、前端文案、生产构建和浏览器烟测。

## 人工检查

- 首次模型配置可以完成读取模型、流式测试和保存。
- DOCX 上传后能调整正文范围；标题、题注、关键词和参考文献默认不选。正文段落即使含行内公式、图片或域，普通文字仍可选，对象自身保持不变。
- 首个模型正文增量会立即显示；停止后只继续未完成块。
- Diff 支持采用改写、保留原文、手动编辑和重新改写。
- 开始改写和完成后继续改写都可以选择 1–3 轮及每轮提示词；N 轮只能产生 N 次串行调用，所选配置必须真实进入任务快照和上游请求。
- 暂停后继续只运行未完成块，并保持原任务的模型、每轮提示词、分块和并发快照。
- 数字、引用、URL 或用户保护词发生变化时只提醒；提醒不得改变结果、触发重试或阻止用户按当前审阅结果导出。
- DOCX 导出只允许已选文本节点发生变化，并明确提示文字长度可能影响换行和分页。
- TXT 明确标注为纯文本，不包含 Word 排版。
- 默认界面不出现 SSE、checkpoint、provider route 等内部术语。

## 仓库卫生

- `git diff --check` 无错误。
- 不跟踪 `tmp/`、`finish/`、`logs/`、`app/dist/`、真实 DOCX/PDF、密钥或本机配置。
- README、启动脚本、CI 与实际命令一致。
